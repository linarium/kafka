# Шаг 1. Создание топика (3 партиции, replication factor 2)

Перед удалением/пересозданием топика остановите приложение (активные консьюмеры удерживают топик):
docker compose stop kafka-demo

Команда (из хоста, к брокеру на localhost:9092):

docker exec kafka1 kafka-topics --create --topic homework-events --partitions 3 --replication-factor 2 --bootstrap-server kafka1:29092 --if-not-exists

Альтернатива с хоста (если kafka1 проброшен на 9092):

docker exec kafka1 kafka-topics --create --topic homework-events --partitions 3 --replication-factor 2 --bootstrap-server localhost:9092 --if-not-exists

---

# Подробное описание топика (kafka-topics --describe)

Команда:

docker exec kafka1 kafka-topics --describe --topic homework-events --bootstrap-server kafka1:29092

С хоста (как в формулировке задания с localhost:9092):

docker exec kafka1 kafka-topics --describe --topic homework-events --bootstrap-server localhost:9092
